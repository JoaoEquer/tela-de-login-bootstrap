# tela-de-login-bootstrap

Tela de login estática em HTML com Bootstrap 5.3 (tema escuro), baseada no exemplo "Sign in" da documentação do Bootstrap.

Demo: https://joaoequer.github.io/tela-de-login-bootstrap/LOGIN-FORM/

## Funcionalidades

- Formulário com e-mail, senha e "Remember me" usando `form-floating`.
- Apenas layout: não há JavaScript nem autenticação.

## Tecnologias

HTML5 e Bootstrap 5.3.1 via CDN (jsDelivr).

## Como rodar localmente

Sem build: abra `LOGIN-FORM/index.html` no navegador (precisa de internet para carregar o Bootstrap).

## Estrutura

- `LOGIN-FORM/index.html` - a tela de login
- `style.css` - arquivo de estilos, não referenciado pela página
